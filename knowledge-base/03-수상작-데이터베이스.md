## 요약 통계

- 총 21팀, 총 상금 1억원(3개 부문 균등 — 각 부문 2,500만~5,000만원)
- **부문별 7 / 7 / 7** (아이디어 기획 / 제품·서비스 개발 / 데이터 분석)
- ⚠️ 데이터 분석 부문(7건, e15~e21)은 **14회 공모요강에 부문 자체가 없음** — 발전량예측·기상보정류 모델은
  14회에는 "제품·서비스 개발"(시제품/데모 형태) 또는 "아이디어 기획"으로 재구성해 응모해야 할 가능성이 높음
- 21건 중 **14회 공식 주관기관(20개)의 데이터를 직접 쓴 사례는 8건뿐** (`institutions_official_organizer_14th: true`)
  → 나머지는 한국전력공사/한국전력거래소(KEPCO/KPX, 비주관기관이지만 산업통상자원부 산하 공기업이라 규정상 사용 가능)나
  지정과제용 비공개 데이터셋에 의존. 즉 **산업통상부 주관기관 20곳의 데이터만으로 상위권에 든 사례는 생각보다 적다** —
  거꾸로 말하면 이 20개 기관 데이터를 제대로 파고든 팀에게는 차별화 기회가 크다.
