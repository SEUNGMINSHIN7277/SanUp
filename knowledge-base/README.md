# 지식베이스 인덱스 — 산업통상부 공모전 수상 전문가 두뇌

제14회(2026) 산업통상부 공공데이터 활용 아이디어 공모전 수상을 목표로 구축한 지식베이스입니다.
공식 규정 원문 + 2025년(13회) 수상작 21건 + 공공데이터 카탈로그를 지식그래프로 엮어, 새 아이디어를
검증하거나 생성할 때 근거 데이터로 사용합니다.

## 새 아이디어를 검증하는 표준 절차

1. **자격 확인**: `01-공모전-공식규정.md` §2 — 산업통상부(산하기관 포함) 데이터를 핵심 로직에 쓰는가?
2. **중복 리스크 확인**: `03-수상작-데이터베이스.json`에서 유사 테마/데이터 조합이 이미 수상했는지 검색
3. **차별화 포인트 확인**: `04-지식그래프.md`의 블루오션 기관 목록과 겹치는가? 겹치면 우선순위 ↑
4. **성공패턴 대조**: `05-수상패턴분석.md`의 대상/최우수 공식(다중 데이터 연계+정량성과+AI 의인화, 또는
   기존자산 편승+복수가치 동시달성)과 얼마나 부합하는지 자가 채점
5. **문서화**: `06-전략플레이북.md` §4 템플릿으로 기획서 작성, §5 체크리스트로 최종 점검
6. **데이터 실존 검증**: `07-공공데이터포털-API-연동.md`의 `scripts/odcloud_search.py`로 실제 데이터셋 존재 확인

## 이 지식베이스의 한계 (정직하게 명시)

- 2025년(13회) 수상작 21건은 **사용자가 제공한 정리표**가 1차 소스이며, 원본 심사자료나 발표자료를
  직접 열람하지는 않았습니다. 세부 서술은 정리표 표현을 최대한 보존했습니다.
- `02-데이터-제공기관-지도.md`는 20개 기관 병렬 WebSearch 리서치(`data/institution-research.json`)로
  data.go.kr 데이터셋 URL 다수를 검증(`verified: true`)했지만, 이는 **검색 스니펫 기반 확인**이며
  WebFetch로 각 페이지 본문(정확한 컬럼 스키마·최신 갱신주기·API 활성 상태)까지 열람한 것은 아닙니다.
  실제 활용 전 data.go.kr에서 재확인 필요.
- 이 세션의 샌드박스 네트워크 정책상 `api.odcloud.kr` 라이브 호출(사용자 제공 API 키)이 실패했습니다 —
  이 API를 통한 추가 실데이터 검증은 로컬 실행 이후 갱신이 필요합니다(`07-공공데이터포털-API-연동.md` 참고).
- "13회 대비 변경점"(팀 인원, 데이터분석 부문 폐지 등) 일부는 웹 검색 요약에 의존했으며, 100% 원문
  대조가 아닌 항목은 문서 내 명시적으로 신뢰도를 표기했습니다.
