# 05. 수상 패턴 분석 — 등급별 당선 공식

21건(2025/13회)을 심사기준(`01-공모전-공식규정.md` §4)에 대응시켜 역설계한 결과입니다.

## 대상(大賞) 3건의 공통 DNA

| 작품 | 핵심 공통 요소 |
|---|---|
| EasyTrax(아이디어기획) | ① 데이터를 여러 개 **연계**(국가정보+시장보고서+빅데이터시각화) ② "개인 전담 에이전트"라는 **의인화된 AI 프레이밍** ③ 문제 정의가 명확(중소 식품기업의 수출 규제 리스크) |
| Shannon(제품서비스개발) | ① **17만개 전체 데이터셋**이라는 압도적 스케일 프레이밍 ② 지식그래프+LLM이라는 최신 기술 조합 ③ "적합도 점수"라는 **정량 지표**로 문제해결을 증명 |
| MLP-XGB 기상보정(데이터분석) | ① **93%/44%/41%/51%**라는 구체적 오차감소 수치 제시 ② 앙상블(MLP+XGBoost)이라는 검증된 기법 조합 ③ 비용절감·수익성이라는 **경제적 임팩트로 환산** |

**공통 공식**: `(여러 데이터 연계) + (구체적 정량 성과지표) + (AI의 능동적/의인화된 역할 프레이밍) + (경제적 가치의 환산)`

이는 심사기준의 "발전 가능성(1차 30점)"·"구체성(2차 30점)"·"사업화 가능성(2차 30점)" 3개 최고 배점 항목을
동시에 정조준한 것입니다. **막연한 아이디어가 아니라 숫자로 증명된 아이디어**가 대상을 받았습니다.

## 최우수 3건의 공통 DNA

| 작품 | 핵심 공통 요소 |
|---|---|
| GreenShift AI | 탄소감축 **+** 전력비 절감을 **동시에** 정량화(두 마리 토끼 프레이밍) |
| 밸류체인 AI 분석시스템 | **기존에 이미 상용화된 자사 솔루션(EM-솔루션)** 위에 공공데이터를 얹음 → 사업화 리스크가 낮다는 신뢰 |
| VPP MoE 예측모델 | 최신 학술 아키텍처(Mixture of Experts)를 실무 문제(소규모 VPP 수익률)에 적용 — **기술 참신성 + 실사용자 가치** 결합 |

**공통 공식**: `(기존 자산/트렌드에 편승) + (두 가지 이상 가치를 동시 달성) + (특정 사용자군의 수익을 명시적으로 극대화)`

## 우수·장려의 특징 (진입 장벽이 상대적으로 낮은 패턴)

- 단일 데이터셋 + 단일 기능 아이디어(예: PODY, WeaFine-R)도 우수·장려는 받을 수 있음
- 장려상 다수(ECO B, 해외여행 반입 스캐닝)는 **활용 데이터와 아이디어 소재가 부자연스럽게 매칭**되어 있음 —
  이는 "산업통상부 데이터를 썼다"는 최소 요건은 채웠지만 데이터 활용의 **깊이**가 얕았던 것으로 해석됨
  → 이 지식베이스의 시사점: 데이터를 형식적으로 인용하지 말고 **핵심 로직에 실제로 사용**해야 상위 등급 가능

## 심사기준별 채점 포인트 매핑

| 심사기준 | 대상/최우수가 실제로 한 것 |
|---|---|
| 창의성 | 기존 서비스 목록과 비교 문장을 명시적으로 제시(EasyTrax: "기존 규제 데이터 제공을 넘어") |
| 구체성 | 수치·아키텍처명·구현 흐름을 구체적으로 서술(MLP-XGB: 93%/44%/41%; Shannon: 적합도 점수 계산 로직) |
| 발전 가능성 | 사업화 방향을 명시(밸류체인: 중소 제조기업 대상; GreenShift: 데이터센터 대상) — 타겟 고객군이 분명함 |
| 문제해결 가능성 | 사회적/산업적 어젠다와 연결(탄소중립, 에너지전환, 중소기업 수출애로) — **정부 정책 방향과 정렬된 문제 정의** |
| AI 활용 확산성(가산) | "에이전트", "지식그래프", "LLM" 등 구체적 AI 아키텍처 용어를 제목/설명에 명시 |

## 블루오션 매트릭스 — 미활용 기관 × 검증된 성공패턴

과거 수상작이 검증한 4가지 성공 패턴(① 다중 데이터 연계+정량성과, ② 기존자산 편승, ③ 에이전틱 AI
의인화, ④ 시계열 예측+경제적 환산)을 `04-지식그래프.md`의 블루오션 기관 15곳에 적용하면 아래와 같은
미탐색 조합이 나옵니다. (구체적 시나리오는 `06-전략플레이북.md` §3 참고)

| 미활용 기관 | 성공패턴 적용 아이디어 방향 | 왜 유리한가 |
|---|---|---|
| 한국무역보험공사(K-SURE) | 해외수입자 신용정보 + KOTRA 시장뉴스 연계 → 수출대금 미회수 리스크 예측 에이전트 | EasyTrax와 같은 "수출 리스크" 테마이지만 **미사용 기관**이라 중복 아이템 감점 회피 가능 |
| 한국로봇산업진흥원 | 로봇보급통계 + 산업단지 데이터 → 지방 제조 중소기업 로봇 도입 ROI 진단 에이전트 | "지역활력"(14회 신규 주제)과 직결 |
| 강원랜드 | 지역 관광/경제 데이터 → 폐광지역 대체산업/관광 수요예측 | "지역활력" 주제어와 기관 성격이 가장 직접적으로 부합 |
| 한국가스안전공사 + 한국가스기술공사 | 가스사고 통계 + 설비 데이터 → 시계열/이상탐지 기반 가스안전 예측 시스템 | e03(다꺼)·e13(누수탐지)과 같은 "안전 예측형" 패턴을 미개척 도메인에 이식 |
| 한국제품안전관리원(추가 심화) | 이미 2건 수상(따숨, 안전유통) — 리콜 데이터 + LLM 결합해 "제품 안전 챗봇/에이전트"로 차별화 | 검증된 데이터지만 아직 에이전틱 AI/LLM 결합 사례는 없음(가산점 5점 공략) |
| 한국세라믹기술원 / 한국탄소산업진흥원 | 소재기술 데이터 + Shannon류 지식그래프 방식 → 탄소중립 신소재 매칭 추천 서비스 | 완전 미개척, 정부 탄소중립 정책 어젠다와 정렬 |

## 경고: 레드오션 영역

- **전력/에너지 발전량 예측 + 시계열 앙상블** 조합은 이미 11건이 수상(21건 중 절반 이상). 유사 아이디어는
  1차 심사 "아이템 중복 여부" 체크에서 불리할 가능성이 높음. 이 영역에 도전한다면 **전혀 다른 각도**
  (예: 공급망 관점, 소비자 관점)로 차별화가 필수.
- **무역/수출 규제 매칭**(EasyTrax류)도 이미 대상 수상 + 훈련자료 "아이디어4" 예시로도 등장 — 이미 상당히
  포화된 방향. 도전한다면 KOTRA 단독이 아니라 **미사용 기관(K-SURE, 무역안보관리원)과 결합**해 차별화 권장.
