# 04. 지식그래프 — 기관 · 수상작 · 테마 · 기술 · 심사기준

기계 판독용 원본은 `graph.json` (노드/엣지 배열, jq로 바로 질의 가능). 이 문서는 그 구조를 사람이
이해하기 위한 시각화 + 사용법입니다.

## 스키마

**노드 타입**: `institution`(24: 20개 14회 주관기관 + 2025 수상작에서 실제 쓰인 비주관기관 4개) ·
`entry`(21개 수상작, `03-수상작-데이터베이스.json`과 id로 연결) · `theme`(14개) · `technique`(10개) ·
`criterion`(10개, 1차/2차 심사 항목)

**관계(edge relation)**:
- `provides_data_for` : 기관 → 수상작
- `addresses` : 수상작 → 테마
- `employs` : 수상작 → 기술
- `scored_strong_on` : 수상작 → 심사기준 (대상/최우수급에서 특히 강했던 항목, 정성 태깅)
- `commonly_paired_with` : 테마 ↔ 기술/기관 (여러 수상작에 걸친 집계 패턴, weight=빈도)

## 핵심 인사이트 3가지 (그래프에서 바로 읽히는 것)

### ① 전력·에너지 데이터로의 극단적 쏠림
21건 중 11건(52%)이 전력/에너지/기상 데이터를 사용. 그 중 5건은 **한국전력공사(KEPCO)**,
1건은 **한국전력거래소(KPX)** — 둘 다 14회 공식 주관기관 20개 목록에는 없습니다. 즉 이 영역은
① 매우 치열한 레드오션이고 ② 상당수가 "산업통상부 산하 공공기관" 조항으로 우회 참여한 것이라
데이터 접근성이 실제로 더 어려울 수 있습니다(한전 데이터는 계약고객 대상 15분 단위 전력데이터처럼
일반 공개 API가 아닌 경우가 많음 — 원문에 "한전 제공 기업 과거 1년치" 라고 명시된 것도 이 때문으로 추정).

### ② 20개 주관기관 중 15개가 완전 미활용 (블루오션)
강원랜드, 무역안보관리원, 한국가스공사·가스기술공사·가스안전공사, 한국디자인진흥원, 한국로봇산업진흥원,
한국무역보험공사, 한국석유공사, 한국석유관리원, 한국세라믹기술원, KEIT, KIAT, 한국탄소산업진흥원,
한국산업기술시험원(KTL) — 이 15개 기관의 데이터는 2025년 수상작 어디에도 등장하지 않았습니다.
이 기관들은 명백히 14회 공식 주관기관이므로 데이터 사용 자격 논란 없이 곧바로 활용 가능합니다.

### ③ "지역활력" 신규 테마와 매칭되는 기관이 아직 비어있다
14회 주제에 새로 들어간 "지역활력"과 가장 직접적으로 연결되는 기관(강원랜드=지역관광경제,
한국산업단지공단=지역 산업단지, 한국로봇산업진흥원=지역 제조업 자동화)이 모두 블루오션 목록에
있습니다 → `06-전략플레이북.md`에서 이 조합을 우선순위로 제안합니다.

## graph.json 조회 예시 (jq)

```bash
# 블루오션 기관 목록
jq '.blue_ocean_institutions' knowledge-base/graph.json

# "재생에너지 발전량예측" 테마와 짝지어진 기술/기관 찾기
jq '.edges[] | select(.source=="theme:renewable_forecast" or .target=="theme:renewable_forecast")' knowledge-base/graph.json

# 특정 수상작(e08 Shannon)이 어떤 기관/테마/기술과 연결되는지
jq '.edges[] | select(.source=="e08" or .target=="e08")' knowledge-base/graph.json

# 대상/최우수급이 강했던 심사기준 확인
jq '.edges[] | select(.relation=="scored_strong_on")' knowledge-base/graph.json
```

## 새 아이디어를 그래프에 추가하는 법

새 아이디어 후보를 검증할 때는 `graph.json`에 임시 노드(`id: "candidate:내아이디어"`)를 추가하고
`provides_data_for`/`addresses`/`employs` 엣지를 연결해본 뒤, 다음을 확인하세요:
1. 연결된 기관이 `organizer_14th: true`인가? (아니면 실격 위험)
2. 연결된 테마가 블루오션(미사용 기관)과 겹치는가, 아니면 레드오션(전력/에너지)과 겹치는가?
3. `employs`로 연결한 기술이 `scored_strong_on` 패턴(에이전틱AI/지식그래프/시계열앙상블)과 일치하는가?
