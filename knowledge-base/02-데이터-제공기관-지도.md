# 02. 데이터 제공기관 지도 (20개 기관)

> **상태: 잠정본(v1)**. 아래 표의 "대표 데이터셋"은 이 지식베이스 구축 시점(2026-07-02)에
> 일반 지식 + 훈련자료/수상작 근거를 바탕으로 정리한 것이며 `verified` 표시가 없는 항목은
> **실제 데이터셋명과 다를 수 있습니다.** 백그라운드로 실행한 웹 리서치 결과 및
> `scripts/odcloud_search.py`(공공데이터포털 검색 API)로 검증되는 대로 이 문서를 갱신합니다.
> 최종 확인은 반드시 datacontest.kr 공공데이터 목록 페이지 또는 data.go.kr에서 하세요.

## 기관 분류 — 반드시 구분할 것

| 분류 | 의미 |
|---|---|
| **14회 공식 주관기관(20개)** | `01-공모전-공식규정.md`에 명시된 기관. 이 기관들의 데이터는 이견 없이 사용 가능 |
| **비주관기관이나 규정상 사용 가능** | "산업통상부 산하 공공기관 포함"이라는 규정 문구 덕분에 사용 가능한 기관(예: 한국전력공사·한국전력거래소). 2025년 수상작 다수가 이 경로를 사용했지만, 데이터 접근 난이도(비공개 API, 기업 전용 데이터 등)가 있을 수 있음 |
| **완전 외부기관** | 산업통상부 산하가 아닌 기관(예: 환경부, 기상청) — "필요할 경우 타 기관 공공데이터 연계 사용 가능" 조항으로만 보조적으로 사용 가능, **단독 핵심 데이터로는 실격 위험** |

## 검증 방법 (다음 액션)

1. `python3 scripts/odcloud_search.py --batch` 를 네트워크 제약 없는 환경에서 실행 →
   `knowledge-base/data/odcloud/<기관명>.json` 생성
2. 결과를 이 세션에 알려주면 위 표의 "대표 데이터셋"란을 실제 데이터셋명으로 교체하고 `verified: true` 태깅
3. 백그라운드 리서치 워크플로우(WebSearch 기반) 결과가 도착하면 교차 검증 후 반영 예정
